# Documentation technique au carré (version de test)

Widget personnalisé pour Grist : il affiche les fiches de documentation technique d'un document Grist, avec un menu par catégorie et une recherche, en mode clair et en mode sombre.

## Ce que contient ce dépôt

- `index.html` : le widget, dans un seul fichier. Grist le charge depuis GitHub Pages.
- `LICENSE-polices.txt` : la licence des polices intégrées (Montserrat, licence SIL OFL).

Ce dépôt ne contient aucune donnée. Les fiches viennent de la table Documentation_technique du document Grist qui charge le widget, avec l'accès « read table » (lecture seule). Le widget n'écrit rien dans Grist et n'envoie rien ailleurs.

## À savoir

Ce dépôt est une version de test, générée à partir d'un autre dépôt. Ne modifiez pas `index.html` à la main : il sera remplacé à chaque nouvelle version.
